# Localization — 本土化校准层（L1）

> **给中国顾客用本 skill 前必读**。原书框架（L0）来自欧美，判断阈值与配色实例以欧美人种/文化为标定。
> 本层（L1）标注哪些可直接用、哪些**必须校准**，校准值以中国顾客样本实测为准。
> 与 L2 品牌实例层（`aesthetic_preference`，默认宋韵）的关系：L1 修判据，L2 给配色/话术实例，两层叠加使用。

## 三层架构

```
L0 普适骨架层   原书框架/方法论（三色素科学、三特质、6档线条、同轴匹配、穿着成本公式）→ 直接用
L1 本土化校准层 本文件：中国人种阈值修正（肤色 L*/b*、骨架身高、风格文化映射、中性色）
L2 品牌实例层    aesthetic_preference（默认宋韵）：配色盘/话术/单品实例
```

## L1 校准判据（中国肤色）

> 以下经验值待 20-30 名真实中国顾客样本精修；精修前作为过渡校准使用。
>
> **2026-09-28 首轮样本精修（15 张：9 Pexels 素材 + 6 知乎真实光手机自拍）**：
> - **b\* 结论**：冷调界 6→5（15 张中无一张 b*<6，东亚冷调极少）；强暖界 12→13（b* P90≈13.5）；
>   golden 界 11→12；温和暖界 8 保留（P50≈9）。
> - **L\* 结论**：真实光样本（6 张手机自拍）L* 69.5-74.7 → **判白界 65 确认**（真实光样本全部 ≥65）；
>   Pexels 素材 L* 52-68 被修图压低，不作 L* 依据。
> - 注意：知乎样本来自公开自拍帖，存在轻微美颜/阴影可能；正式定标仍需真人实测（20-30 名顾客）。

1. **判白门槛**：`L*≥70 → L*≥65`（2026-09-28 真实光样本 6 张手机自拍 L* 69.5-74.7 验证：中国女性手机自拍普遍 ≥65；70 门槛会误判"自然"档）。
2. **暖冷判定**：`b*/a* 比值法对东亚失效`（b* 8-15、a* 低 → 比值几乎恒 >1.25 → 全员暖调，暖冷轴区分度归零）。改用**绝对 b\* 分档**：
   - b\* ≥ 13 → 强暖（黄调明显）
   - 8 ≤ b\* < 13 → 温和暖
   - 5 ≤ b\* < 8 → 中性
   - b\* < 5 → 冷调
   - 同时参考 a\*（低 a\* = 红调少，偏黄绿感）。
3. **金黄感**：`golden = b*≥9` 对东亚偏松（b*9 是常态而非特征）。改为 `b*≥12` 才算强金黄感。
4. **骨架身高分档**：大 >168cm / 普通 158-168cm / 小 <158cm（中国女性均值约 158-160；原 >170/160-170/<160 是欧美标定）。
5. **风格类型映射**（详见 stylist-kb 映射表）：原书四类型是欧美文化标签，给中国顾客用先过映射表再谈"适合的风格"。
6. **中性色**：原书中性色10色（海军蓝/可可/巧克力棕等）是欧美审美骨架，中国场景优先 L2 宋韵中性色实例；原表仅作"非品牌语境"时的参考。

## 使用纪律

- **引用原书结论前**先查本章"需 L1 校准部分"列，有则改用 L1 值。
- **L1 与 L0 冲突时 L1 优先**（L0 是欧美标定源，L1 是中国修正）。
- **L1 与 L2 分工**：L1 管"判据对不对"，L2 管"配色/话术用什么"；L2 实例默认宋韵，但可被顾客品牌偏好覆盖。
- **样本精修后**更新本文件"校准判据"节的数值并记日期，勿凭印象改。
