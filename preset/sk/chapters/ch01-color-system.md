# Chapter 1: AIS 季节色彩系统

## Core Idea
原书用 **AIS 季节色彩系统**取代单一四季色系：因为"没有一个人是完全的温暖或寒冷"，所以每人 = 主型 + 次型 + 中性色表，由此架构出反映个人肤色/眼/发的独特调色盘。

## Frameworks Introduced
- **AIS 三特质**
  - When to use: 判读任何人的色彩属性时
  - How: 色调(暖/冷/纯) × 明度(深/浅) × 彩度(亮/浊) 三轴交叉
- **6 型主要色彩**（深/浅/亮/浊/暖/冷）
  - When to use: 确定主型
  - How: 以发/眼/肤的整体投射为判据，选出最主导的一型
- **主型 + 次型 + 中性色表**
  - When to use: 构建个人调色盘
  - How: 主型定基调，次型补变化，中性色（黑/灰/灰褐/蜂蜜色/海军蓝/暗灰黄/可可/巧克力棕/深梅子/白）做骨架

## Key Concepts
- **黑色素/黄色素/血红素**：肤色的三色素构成，黑色素偏暖——AIS 科学基础
- **主要颜色（主型）**：6 型中你最主导的一型
- **次要颜色（次型）**：补充主型的第二型
- **中性色表**：10 个百搭骨架色
- **职业可信度色**：深蓝/棕/驼/灰——职业场景提可信度
- **季节色系（四季）**：大众标签，AIS 视其为不够精确的入门工具

## Mental Models
- **"人人有暖色，只是多少"** → 不要把人硬塞进纯暖或纯冷，永远看比例。
- **"无法确定就选最喜欢的"** → 判定入口卡住时的兜底原则：偏好往往指向真实属性。
- **"季节是大众标签，6 型是精确配色盘"** → 四季用来入门沟通，6 型用来精确配色。

## Worked Example
**判定入口三问**（原书方法，p-005 附近）：
1. 你属于**暖色**还是**冷色**？
2. 你属于**深色**还是**浅色**？
3. 你属于**浊色**还是**亮色**？

三问的答案交集 → 锁定主型。若某问无法确定，**选你最喜欢的颜色**——原书认为偏好与真实属性高度相关。

**原书权威说法**（p-004-005）：
> "在过去几年中广受欢迎的四季色彩系统，让许多女性开始寻找自己的'颜色'。但是许多人却搞不清楚自己究竟属于哪一个季节色系。你可能被甲色彩顾问判断为属于春季色系，却被乙顾问诊断为属于夏季色系。"
> "我发现没有一个人是完全的'温暖(warm)'或'寒冷(cool)'。我们所有人都具备这两种特质，只是比例高低的差异而已。"

→ 这正是 AIS 扩充四季、改用 6 型的根本理由。

## Key Takeaways
1. 不要用单一季节给人定性——人都是暖冷混合，看比例。
2. 色彩鉴定走"主型+次型+中性色"三层，不是只定一个季节。
3. 判定卡住时"选最喜欢的"是原书认可的兜底，不是妥协。
4. 职业场景的提可信度色是固定的：深蓝/棕/驼/灰。
5. AIS 的科学根在肤色的三色素（黑色素/黄色素/血红素），不是审美主观。
