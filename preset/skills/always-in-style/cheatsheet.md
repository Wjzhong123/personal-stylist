# Cheatsheet — AIS 快速决策表

> 单页决策指南。每一行帮你"决定"一件事，不是术语表（那是 glossary）也不是论述（那是 chapters）。

## 色彩判定决策表

| 三问答案 | → 主型 |
|---|---|
| 暖 + 深 + 亮 | 暖型/深型（看主投射）|
| 暖 + 浅 + 浊 | 暖型/浅型 |
| 冷 + 深 + 亮 | 冷型/深型 |
| 冷 + 浅 + 浊 | 冷型/浅型 |
| 纯 + 亮 | 亮型 |
| 纯 + 浊 | 浊型 |

- **某问答不上 → 选最喜欢的颜色**（原书兜底，非妥协）
- **定案铁律**：自评只给初判，色季必须走问卷（银/金、血管、黑白）校正后才写入

## 身体线条 ↔ 服装线条匹配表

| 身体线条 | 推荐服装线条 | 效果 | 风险 |
|---|---|---|---|
| 棱角直线/直线 | 棱角直线/直线 | 强化气场、锐利 | 过度则显生硬 |
| 柔和直线/混合 | 柔和直线/混合 | 协调、安全 | 不出彩 |
| 柔和曲线/曲线 | 柔和曲线/曲线 | 柔美、顺应 | 过度则显松垮 |
| **不明** | **柔和直线** | **大众安全区兜底** | 对谁都"不出错" |

- **跨档红线**：曲线身体穿棱角直线 = 违和；直线身体穿曲线 = 显胖
- **判定兜底**：轮廓看不准 → 看脸型（方/尖=直线系，圆=曲线系）

## 场合 × 风格 × 可信度色

| 场合 | 默认风格 | 可信度色 | 备注 |
|---|---|---|---|
| 职业 | 优雅（保守面貌）| 深蓝/棕/驼/灰 | 提可信度优先 |
| 休闲 | 自然 | 无强制 | 舒适为主 |
| 社交 | 可放大个性（夸张/浪漫）| 无强制 | 表达为主 |

- **优雅 ≠ 人格**：它是"场合需要的保守面貌"，任何人职业场合都可用
- **先定场合再选风格**，不要把风格当固定人格标签

## 衣橱诊断信号表

| 信号 | 诊断 | 动作 |
|---|---|---|
| "没有衣服穿" | 时间配置与衣橱比例失衡 | 半年复查时间分配对照 |
| 单品多但搭不出 | 缺中性色骨架 | 补海军蓝/灰/白等 |
| 场合缺覆盖 | 基本衣橱检查表有缺口 | 按检查表补（短外套/白衬衫/大衣等）|
| 颜色太散 | 没走 3 色衣橱法 | 收敛到 3 主色+中性色 |

## 购物决策规则

- **黄金准则**："除非你疯狂地爱它、极度需要它，否则就不要买它"
- **穿着成本公式**：`购买成本 ÷ 预期穿着次数 = 每次穿着成本`（100美元裙/26次=3.84 vs 150美元礼服/5次=30）→ 价格低≠成本低，穿着次数才是
- **黑裙必备**：基本黑裙装 = "穿上就永远穿着得体"，正式场合传统单品
- **缺口优先**：先补基本衣橱检查表缺口，再买个性款
- **骨架约束**：小骨架(<160)慎选重面料+挺直线，会显压迫

## 速判阈值

- **色季置信**：≥0.8 自动回填 / 0.6-0.8 建议确认 / <0.6 待人工（客观度量+问卷校正）
- **骨架分档**：>170cm 大 / 160-170cm 普通 / <160cm 小
- **主色上限**：单套主色 ≤3 个（防视觉过载）
