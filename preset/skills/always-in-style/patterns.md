# Patterns — AIS 系统的搭配技法与决策模式

> 原书可复用的具体技法。每条含：何时用、怎么做、权衡。

## Pattern 1: 色彩判定入口三问法
**When to use**: 给任何人做色彩鉴定时
**How**:
1. 问"你属于暖色还是冷色？"
2. 问"你属于深色还是浅色？"
3. 问"你属于浊色还是亮色？"
4. 三问交集 → 锁定 6 型主型
5. **某问卡住 → 选你最喜欢的颜色**（原书兜底原则，偏好与真实属性高度相关）
**Trade-offs**: 三问法快但依赖自评，对色彩感知弱的人可能误判 → 此时应走客观度量（肤色采样）+ 问卷校正，不靠自评定案。

## Pattern 2: 个人调色盘三层架构法
**When to use**: 构建某人的长期用色盘
**How**: 主型（定基调）+ 次型（补变化）+ 中性色表（做骨架，10 色任选）→ 三层叠加
**Trade-offs**: 三层结构比单一季节色系精确，但要先准确定主型；主型错则全盘错。

## Pattern 3: 身体线条↔服装线条同轴匹配法
**When to use**: 选版型、判断某件衣服是否适合某人
**How**:
1. 定身体线条档（6 档之一）
2. 看服装线条档（看肩线/前襟线/下摆线）
3. 同档或相邻档 → 匹配；跨档（如曲线身体穿棱角直线）→ 违和
4. 身体线条不明 → 选柔和直线（大众安全区）兜底
**Trade-offs**: 同轴匹配最协调但最不出彩；想强化气场可故意同档强化（直线身体+棱角直线装），但不可跨档。

## Pattern 4: 脸型兜底判定法
**When to use**: 身体轮廓看不准（如照片角度差、穿得宽松）
**How**:
1. 看脸型：方/长/菱/尖下巴 → 直线系
2. 圆润 → 曲线系
3. 由脸型回推身体线条档位
**Trade-offs**: 脸型通常同步身体，但非 100%；面部脂肪多时会干扰轮廓判读，需结合肩胯骨判断。

## Pattern 5: 3 色衣橱构建法
**When to use**: 衣橱诊断与重构
**How**:
1. 选 3 个相配的主色（基于个人调色盘的主型+次型）
2. 加中性色补充（海军蓝/灰/白等骨架色）
3. 少量单品 × 多组合 → 覆盖多数场合
4. 对照基本衣橱检查表找缺口
**Trade-offs**: 3 色法极简高效，但对需要多风格表达的人偏保守；可按场合拆多组 3 色。

## Pattern 6: 场合优先风格选择法
**When to use**: 选风格时
**How**:
1. 先定场合（职业/休闲/社交）
2. 再从四风格（夸张/优雅/自然/浪漫）中选
3. 优雅 = 该场合的保守面貌（默认安全项）
4. 职业场景固定提可信度色（深蓝/棕/驼/灰）
**Trade-offs**: 场合优先避免"把风格当人格固化"；但极端个性表达者可能觉得受场合束缚 → 社交场合可放大个性风格。

## Pattern 7: 裙长腿长视觉调整法
**When to use**: 选裙长/外套长
**How**:
- 小腿长 → 可穿及踝长裙（流行款也撑得住）
- 小腿短 → 裙勿过长 + 外套弄短提腰线
**Trade-offs**: 服从视觉比例而非服从流行；短腿者放弃流行长裙是必要妥协。

## Pattern 8: 面料结构调柔和度法
**When to use**: 想让直线服装变柔和（或反之）
**How**:
- 想柔和 → 选松散/轻软面料结构（柔和线：雪纺/绉纱/平针织/结子花呢）
- 想挺直 → 选细密/重面料（挺直线：亚麻/华达呢/绒面呢/法兰绒）
**Trade-offs**: 同一剪裁配不同面料可改变线条柔和度，灵活性高；但重面料对小骨架有压迫感，需结合骨架档选。

## Pattern 9: 服装穿着成本公式法（p-158 原文）
**When to use**: 任何购物决策、衣橱单品价值评估
**How**: `衣服购买成本 / 预期穿着次数 = 每次穿着成本` → 用此值横向比较，不用绝对价格
**实例**: 100美元裙装/26次=3.84美元/次 vs 150美元晚礼服/5次=30美元/次 → 晚礼服虽便宜50美元，每次成本是裙装近8倍
**Trade-offs**: 公式简单但依赖"预期穿着次数"预估准；高频基础款用此公式价值最大，低频特殊场合款（婚纱/礼服）需另估情感/仪式价值。原书："最好的服装投资 = 穿起来感觉好、愿意一穿再穿的"。
