## Core Frameworks & Mental Models

本书的统一框架是 **AIS (Always In Style) 系统**——"流行会变，但个人风格不变，它始终是个人性的写照"。AIS 不靠流行驱动，而靠**对你自身外形特征的精确判读**来构造搭配逻辑。五个子系统：

### 1. AIS 季节色彩系统（扩充四季）
- **科学基础**（p-005 原文）：肤色 = 黑色素(暖) + 黄色素 + 血红素。**"没有一个人是完全的'温暖'或'寒冷'，所有人都具备这两种特质，只是比例高低的差异"** → 单一季节色系无法充分描述每个人。
- **三特质**：色调(暖/冷/纯) × 明度(深/浅) × 彩度(亮/浊)
- **6 型主要色彩**：深色 / 浅色 / 亮色 / 浊色 / 暖色 / 冷色（判据 = 发/眼/肤整体投射）
- **每人 = 主型 + 次型 + 中性色表**（黑/灰/灰褐/蜂蜜色/海军蓝/暗灰黄/可可/巧克力棕/深梅子/白）
- **判定入口**（原书方法）："你属于暖色还是冷色 / 深色还是浅色 / 浊色还是亮色"——**无法确定时选最喜欢的颜色**。
- **职业可信度色**：深蓝 / 棕 / 驼 / 灰。
- *Use when*: 给人做色彩鉴定、配色盘构建、职业着装选色。

### 2. 身体线条系统（版型第一坐标）
- **6 档**：棱角直线型 → 直线型 → 柔和直线型 → 混合型 → 柔和曲线型 → 曲线型
- **判定**：穿影子/紧身衣看整体轮廓；**拿不准看脸型**（方/长/菱/尖下巴 = 直线系，圆润 = 曲线系）
- **同轴匹配原则**：服装线条档应与身体线条档同轴呼应（见 ch03 服装线条）
- **骨架 × 布料 × 线条表**：>170cm 大骨架 / 160-170cm 普通 / <160cm 小骨架 → 决定布料重量与线条档配合
- **裙长 × 腿长视觉错觉**：小腿长 → 可穿流行长裙；小腿短 → 裙勿过长、外套弄短
- *Use when*: 决定版型、判断某人适合直线还是曲线剪裁。

### 3. 服装线条（第三篇，p-049 原文）
- 服装的**轮廓线条 = 衣服的剪裁或外部线条**，跟身体一样分棱角直线 / 直线 / 柔和直线 / 混合 / 柔和曲线 / 曲线
- **柔和直线型**是"大多数服装厂商生产"的线条——因为没有极端直线或曲线，**不论直线身体线条或曲线身体线条者都可穿**（大众款的安全区）
- *Use when*: 选品、判断某件衣服适合什么体型。

### 4. 风格四类型 × 场合
- **四风格**：夸张 / 优雅 / 自然 / 浪漫
- **三维场合**：职业 / 休闲 / 社交 → 二维场合表
- **关键定义**："优雅 = 每个人按场合需要的保守面貌"——优雅是场合能力，不是人格标签
- **职业场景**：深蓝/棕/驼/灰 提可信度
- *Use when*: 先定场合，再选风格；不要把风格当人格固化。

### 5. 衣橱规划
- **3 色衣橱法**：3 个相配色 + 中性色补充 → 少量单品大量组合
- **时间分配对照**："没有衣服穿"的真相 = 时间配置与衣橱比例失衡，每半年复查
- **基本衣橱检查表**：短外套 / 衬衫×3(白衬衫必备) / 裤 / 裙 / 毛衣×2 / 裙装×2 / 大衣 / 晚礼服
- **购物黄金准则**（p-010 原文精神）："除非你疯狂地爱它、极度需要它，否则就不要买它"
- **黑色裙装传统**（p-010 原文）："小小的黑色裙装已经成为正式场合的传统穿着，是社交场合的必备单品……只要穿上你的基本黑裙装，你就永远'穿着得体'"
- *Use when*: 衣橱诊断、购物决策、缺口清单。

### 面料分类（支撑）
- **柔和线**：雪纺 / 绉纱 / 平针织 / 结子花呢
- **挺直线**：亚麻 / 华达呢 / 绒面呢 / 法兰绒
