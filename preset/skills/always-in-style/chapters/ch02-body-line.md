# Chapter 2: 身体线条系统

## Core Idea
身体线条是**版型第一坐标**——把人的整体轮廓分 6 档，服装线条应与之同轴匹配。它比"体型"更基础，因为线条决定轮廓走向，体型只决定局部比例。

## Frameworks Introduced
- **身体线条 6 档**
  - When to use: 任何人选版型的第一步
  - How: 棱角直线型 → 直线型 → 柔和直线型 → 混合型 → 柔和曲线型 → 曲线型
- **脸型判定法**
  - When to use: 身体轮廓看不准时
  - How: 方/长/菱/尖下巴 = 直线系；圆润 = 曲线系。脸型与身体线条高度同档。
- **骨架 × 布料 × 线条表**
  - When to use: 选布料重量与线条档配合
  - How: >170cm 大骨架 / 160-170cm 普通 / <160cm 小骨架，骨架越大越能撑重料+挺直线

## Key Concepts
- **身体线条（body line）**：整体轮廓的直曲程度，6 档
- **棱角直线型**：最锐利，骨感分明
- **曲线型**：最圆润，无明显棱角
- **柔和直线 / 柔和曲线**：中间过渡档
- **混合型**：直曲特征都不极端
- **骨架（skeleton）**：大/普通/小三档，独立于线条

## Mental Models
- **"拿不准看脸型"** → 脸是身体线条的微缩样本，脸的直曲通常同步身体。
- **"线条定轮廓，体型修局部"** → 当 body_line 与 body_type 冲突，以 body_line 定大轮廓，body_type 修局部细节。
- **"同轴匹配"** → 直线身体穿直线服装，曲线身体穿曲线服装；错轴会显违和。

## Anti-patterns
- **给曲线身体穿棱角直线装**：轮廓冲突，显生硬
- **只用体型不用线条**：体型（肩腰臀比）是局部，线条是整体走向——只看体型会漏掉直曲基调

## Worked Example
**判定流程**：
1. 让人穿影子/紧身衣（或看全身轮廓照）
2. 观察整体轮廓走向：肩-腰-臀的外缘是直是曲？
3. 走向清晰 → 直接定档（如明显圆润 = 曲线型）
4. 走向模糊 → **看脸型**：下巴方/尖 = 直线系，圆润 = 曲线系，再回推身体档位

**裙长 × 腿长视觉错觉**：
- 小腿长 → 可穿流行的及踝长裙（比例撑得住）
- 小腿短 → 裙勿过长（会压短腿），外套弄短以提腰线

## Key Takeaways
1. 身体线条 6 档是版型第一坐标，先于体型判断。
2. 轮廓看不准时用脸型兜底——脸的直曲同步身体。
3. 服装线条要同轴匹配，错轴显违和。
4. 骨架大小决定布料重量与线条档的配合上限。
5. 裙长选择服从腿长视觉错觉，不是服从流行。
