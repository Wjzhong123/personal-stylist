# Chapter 7: 主要颜色与次要颜色（第七篇 · p-127 原文）

## Core Idea
每人 = **主要颜色 + 次要颜色 + 中性色**，三者整合成个人专属配色盘。主要颜色是别人第一眼看到你的印象，次要颜色增添变化与弹性，中性色是人人适用的骨架。

## Frameworks Introduced
- **主要颜色定位法**（p-128 原文）
  - When to use: 色彩鉴定第一步
  - How: 你是深色/浅色/亮色/浊色/暖色/冷色？→ 别人第一眼印象
  - 注：深/浅/亮最易辨识；暖/冷/浊需更多心思
- **主+次+中性三层配色盘**
  - When to use: 构建个人长期用色盘
  - How: 主型定基调 → 次型补变化 → 中性色做骨架 → 单独用或混合搭
- **浊色系特征**（p-127 原文）
  - When to use: 识别浊色系人
  - How: 适合深浅适中、"无色彩"外观显平衡；单一不鲜明颜色显丰富优雅；暖色系人随年龄/白发增多会转浊色系

## Key Concepts
- **主要颜色**：第一眼印象，6 型之一（深/浅/亮/浊/暖/冷）
- **次要颜色**：与主型互补、分量可接近，增添穿着变化弹性
- **中性色（neutrals）10 色**：黑色 / 各种深浅灰 / 灰褐色(beige) / 蜂蜜色(tan) / 海军蓝(navy) / 暗灰黄色(taupe) / 可可色(cocoa) / 巧克力棕色(chocolate brown) / 深梅子色(deep plum) / 各种深浅白
- **浊色系**：深浅适中、无色彩外观平衡的色型

## Mental Models
- **"主+次+中性 = 个人面貌"** → 单独用主型太单调，加次型添变化，中性色做安全骨架。
- **"中性色人人合适"** → 职场/正式场合首选中性色，对每个人都"不出错"。
- **"主次往往接近甚至分量相等"** → 不要强分主次轻重，两者可互补。
- **"暖色会随年龄变浊"** → 色彩属性不是终身固定，白发增多会推移。

## Anti-patterns
- **只定主型不定次型**：丢失变化弹性，配色盘过窄
- **中性色单独用不加主/次色**：原书说"中性色加上一点儿你的主要或次要色彩混合，才能塑造属于你自己的个人面貌"——纯中性色显不出个性

## Worked Example
**中性色定义原文**（p-127）：
> "黑色、各种深浅程度的灰色、灰褐色(beige)和蜂蜜色(tan)、海军蓝(navy)、暗灰黄色(taupe)、可可色(cocoa)、巧克力棕色(chocolate brown)、深梅子色(deep plum)以及各种深浅不一的白色等颜色，是我们所谓的'中性色(neutral)'。中性色穿在每个人身上都很好看，而且很适合运用在职场或正式场合的服装上。"

**配色盘构建流程**（p-128 原文逻辑）：
1. 定主要颜色（第一眼印象，6 型之一）
2. 找次要颜色（通常主色定了次色就跟出）
3. 整合主+次+中性色 → 个人专属配色盘
4. 单独用或与中性色/其他色搭配

> 原书："把你的主要和次要颜色整合起来，你就可拥有自己专属的配色盘，并可以有更多的选择空间。"

**浊色系识别**（p-127）：
> "适合浊色系人使用的颜色，既不深，也不浅，属于深浅适中的颜色。'无色彩'的外观，看起来会很平衡。这种人如果穿着单一、不鲜明的颜色，会显得很丰富、很优雅。暖色系的人往往会随着年龄增长或白发变多而变成浊色系。"

## Key Takeaways
1. 每人 = 主型 + 次型 + 中性色三层，整合成专属配色盘。
2. 主要颜色 = 第一眼印象，深/浅/亮最易辨，暖/冷/浊需多心思。
3. 中性色 10 色人人合适，职场/正式首选。
4. 中性色别单用——加一点主/次色混合才显个性。
5. 色彩属性会随年龄/发色变化（暖→浊），非终身固定。
